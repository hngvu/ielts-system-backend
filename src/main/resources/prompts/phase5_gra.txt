==================================================
VIOLATION DEFINITIONS & ACTIVATION RULES

too_many_errors:
Activate ONLY IF:

Frequent major errors occur across multiple sentences
AND

These errors interfere with clarity or sentence control.

Do NOT activate if:

Errors are occasional

Meaning remains clear

Complex structures are mostly controlled

limited_sentence_variety:
Activate ONLY IF:

Essay relies predominantly on simple sentences
AND

There is minimal use of subordinate or complex structures.

Do NOT activate if:

Complex structures are present but imperfect

There is visible attempt at varied grammar

frequent_minor_errors:
Activate ONLY IF:

The SAME TYPE of minor grammatical error
(e.g., article misuse, plural agreement)
appears repeatedly across different sentences.

Do NOT activate for:

Isolated slips

Different error types occurring once each

CRITICAL RESTRICTIONS

If a sentence is grammatically correct, it must NOT be cited.

Passive voice is NOT an error if grammatically correct.

Stylistic awkwardness is NOT a grammatical issue.

Vocabulary choice issues must NOT be treated as grammar errors
unless they create structural inaccuracy.

If a violation is inactive:

location must be empty string

evidence must be empty string

reason must be empty string

All string values must be on a single line.

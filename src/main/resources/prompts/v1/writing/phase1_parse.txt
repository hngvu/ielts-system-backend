====================
FIELD DEFINITIONS

word_count
Count total words using whitespace tokenisation.

paragraphs_raw
List all detected paragraphs in original order.

introduction
Copy the first paragraph exactly as written.
Do NOT decide whether it paraphrases the question.

overview
Copy ONLY sentence(s) that explicitly summarise overall/global trends.
If none clearly exists, return "".

conclusion
Copy final paragraph IF it restates global trends.
If none, return "".

overview_analysis.exists
true only if overview is not empty.

overview_analysis.entities_mentioned
List only explicitly written entities.

overview_analysis.trend_statements
Extract only explicit trend statements from overview.

Rules:

One object per explicit trend.

If no clear direction word appears, use "unclear".

Only mark "highest" or "lowest" if explicitly written.

Words like "most", "least", "dominant", "minimal" count as extremes.

overview_analysis.has_extreme
true only if at least one trend statement has is_extreme ≠ "none".

body_paragraphs
Exclude introduction and overview paragraphs.

paragraph_index
Sequential starting at 1.

paragraph_text
Copy paragraph exactly.

entities_mentioned
List only explicitly written entities.

explicit_comparisons
Include only comparisons with explicit comparison language:
"more than", "less than", "higher than", "lower than",
"compared to", "whereas", "while", "in contrast to".

If comparison is implied but not explicit, do not include.

explicit_trends
Extract only explicit directional statements.
Do not infer trend direction.

task_coverage.entities_mentioned_in_essay
List ALL unique explicitly written entities in entire essay.

task_coverage.number_of_paragraphs
Total number of detected paragraphs.

sentences
Split essay into sentences.
Preserve original wording.
Preserve original order.
Do NOT merge or split incorrectly.
Assign sequential sentence_id starting from 1.

====================
CRITICAL CONSTRAINTS

Output MUST be valid RFC 8259 JSON.
Use DOUBLE QUOTES for all keys and strings.
No markdown.
No explanations.
No comments.
No trailing commas.
No text outside JSON.

If a field has no content, return "" or [].
Every required key must appear exactly once.
